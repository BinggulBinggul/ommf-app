    운영진 관리자 인증

    회차별 설정, 신청서 실시간 수신, 공지, QR 암호, 룰렛 및 출석 관리를 위해 비밀번호를 입력하세요.

    Firebase 실시간 서버 연동 완료 (ommfapp-default-rtdb)

    📌 사용자 메인 화면 기본 표시 회차 설정 & 회차 관리

    다른 사용자들이 앱에 들어왔을 때 메인 화면에 기본으로 보여줄 회차를 지정합니다.

    📨 [] 실시간 접수된 참여 신청서 (0건)

    사용자가 제출한 신청서가 실시간으로 이곳에 도착하며, 출석 명단(미출석 상태)에도 자동 등록됩니다.

    📢 [] 접속 공지 팝업 설정

    공지를 저장하면 참여자 접속 시 팝업창과 메인 화면 상단 공지 칸에 표시됩니다.

    🔑 [] 추첨 인증 코드 설정

    참여자가 스캔할 QR 코드의 텍스트 데이터이면서, 수동 입력 시 사용하는 암호입니다.

    📋 [] 사전 등록 참여자 및 출석 체크 관리

    참여 신청 시 자동으로 이곳에 등록되며, 현장에서 [출석완료 / 미출석] 버튼만 눌러 상태를 변경하세요.

    📝 [] 행사 정보 · 소개 · 안내 개별 저장

    현재 선택된 회차의 설명만 독립적으로 서버에 저장됩니다.

    🎲 [] 랜덤 룰렛 상품 및 확률 설정

    상품별 가중치(확률 %)를 실시간으로 조절합니다.

    합계 100

    💾 전체 데이터 파일 백업 및 복원

    기본적으로 Firebase 서버에 실시간 자동 저장되며, 추가로 백업 파일을 내려받거나 복원할 수 있습니다.
